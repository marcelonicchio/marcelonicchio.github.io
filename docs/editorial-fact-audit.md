- Dates and role titles must match between PT and EN.

- “Marcelo Nicchio” remains the canonical primary name; alternate forms are reconciled as aliases.
- WIP status must appear in both languages.
- The current HAI phase must not redefine the lifetime entity as a whole.
- A factual correction in one language triggers a check of the counterpart page and the canonical `/data/` records.

## Launch gating

Before removing `noindex` from a thematic page, confirm:

1. factual copy reviewed;
2. PT/EN pair aligned;
3. public links tested;
4. metadata and canonical/hreflang checked;
5. image/scan rights status known for any visual asset used;
6. no sensitive personal information exposed.
