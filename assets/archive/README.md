# Public archival assets

This directory is reserved for **selected, rights-reviewed public derivatives** used by the Marcelo Nicchio hub.

Do not upload raw master archives here by default.

## Planned folders

- `press/` — selected press/document excerpts
- `music/` — performance, recording and release stills
- `digital/` — historical web/BBS/product material
- `audiovisual/` — production stills and credit frames
- `research/` — site-generated research graphics when needed

## Naming convention

Use stable descriptive lowercase filenames:

`YYYY-source-project-short-description.ext`

Examples:

- `2001-folhateen-orfaos-do-rock-cover-detail.jpg`
- `2006-redetv-meia-noite-e-uns-credits-detail.jpg`
- `2005-mirantte-news-homepage-detail.jpg`

## Required caption metadata

Before an archival image is used publicly, record:

- approximate or exact date
- source / publication / project
- what the image actually documents
- whether it is an original, scan, screenshot, frame capture, crop or reconstruction
- rights/use status
- credit line if required
- whether personal or third-party information was redacted/cropped

## Non-negotiable rules

- No CPF, signatures, personal addresses, obsolete private phone numbers or unnecessary third-party personal data.
- No full CTPS or corporate-contract scans as public proof.
- No full magazine issue simply because a scan exists.
- No AI reconstruction presented as historical evidence.
- A Minduim BBS reconstruction must state clearly that it is a visual reconstruction based on memory, not an original screenshot.
- Preserve masters separately; public web files should be derived copies.
