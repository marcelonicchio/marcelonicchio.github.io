# Meia-Noite e Uns — image intake

Working folder for selected public web images associated with the 2006 RedeTV! project *Meia-Noite e Uns*.

Preferred filename pattern:

`2006-meia-noite-e-uns-XX-short-description.ext`

Examples:

- `2006-meia-noite-e-uns-01-studio.jpg`
- `2006-meia-noite-e-uns-02-soninha-francine.jpg`
- `2006-meia-noite-e-uns-03-production-team.jpg`

Keep original high-resolution masters outside the regular repository by default. Upload selected working/public copies here. Captions, ordering and gallery derivatives will be handled separately during implementation.
